# Binance Glass Scanner (Android)

기존 저장소 `tnehdl02/binanace`에 적용할 수 있는 Android 프로젝트 소스입니다.
패키지: `com.example.binancephonescanner`

## 적용 방법
1. ZIP 압축을 풉니다.
2. `app/` 폴더와 `.github/` 폴더를 기존 저장소에 덮어씁니다. 저장소에 이미 있는 `gradle/`, `gradlew`, 루트 `settings.gradle.kts`, 루트 `build.gradle.kts`는 유지해도 됩니다.
3. GitHub에 커밋/푸시합니다.
4. Actions에서 `Build APK` 워크플로가 완료되면 APK 아티팩트를 받습니다.

## 포함 기능
- 어두운 유리 질감(Glassmorphism) UI
- 여러 감시 설정(감시 1, 감시 2...) 생성/편집/삭제
- 거래량 증가(배율/퍼센트), SMA/EMA 배열, 이동평균선 비교, 가격 등락률 조건
- 조건별 타임프레임: 1m, 5m, 15m, 1h, 4h, 1d
- Binance 현물/USDT-M 선물/둘 다 선택
- 시작 직후 1회 검사, 진행률, 매칭 종목, 최근 검사 로그
- 설정한 분(매시 정각/50분/59분 등)에 반복 검사
- 포그라운드 서비스와 알림

## 중요 제한
- 공개 Binance 시장 데이터만 사용하며 API 키나 주문 실행은 없습니다.
- Android Doze는 네트워크 접근과 백그라운드 실행을 제한할 수 있습니다. 포그라운드 서비스/알람을 사용하지만, 모든 기기에서 Doze 중 네트워크 스캔이 100% 보장되는 것은 아닙니다. 배터리 최적화 제외 권한은 사용자가 시스템 설정에서 직접 허용해야 할 수 있습니다.
- 많은 종목 × 여러 타임프레임을 동시에 검사하면 Binance 공개 API 제한에 걸릴 수 있습니다. 앱은 요청 간격을 두지만, 감시 설정을 과도하게 늘리지 않는 것을 권장합니다.
- 가격 등락률은 선택한 봉의 시가 대비 현재가/봉 가격 변화율 기준입니다. 거래량은 현재 진행 중 봉과 직전 완료 봉의 quote volume을 비교합니다.
